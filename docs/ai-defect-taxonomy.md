# AI Defect Taxonomy

A working set of categories for classifying defects you find while
reviewing AI-generated (or your own AI-assisted) code and tests. Add a row
to the log each time you find a real example - the categories below are a
starting point, not a fixed list; rename or split them once you have enough
examples to see the real shape of what goes wrong.

## Categories

| Category                                | Description                                                                                                                                                      | Example seen so far                                                                                                                                                                                                         |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Overly broad locator**                | A selector matches more elements than the author expected; passes by luck (`.first()`), or fails with a strict-mode violation.                                   | `getByRole('link', { name: 'Sauce' })` matching both the intended link and an unrelated third-party link on the same page - the very first bug fixed in this repo.                                                          |
| **Unverified business-logic assertion** | A test asserts behavior the author assumed rather than confirmed - e.g. "search results contain the search term" without checking what the app actually returns. | Would have shipped as a broken assumption in `flow-01-search-and-view-product.spec.ts` if not cross-checked against the real API response - see `docs/target-application.md`, "Search isn't a strict substring match."      |
| **Silent scope gap**                    | Generated code handles the happy path completely but silently drops an edge case (empty state, error state, cleanup) without saying so.                          | —                                                                                                                                                                                                                           |
| **Hallucinated API/selector**           | References a method, endpoint, or attribute that doesn't exist, or exists with different behavior than assumed.                                                  | —                                                                                                                                                                                                                           |
| **Flaky wait pattern**                  | Reintroduces manual sleeps/polling instead of trusting Playwright's auto-waiting, or waits for the wrong condition.                                              | —                                                                                                                                                                                                                           |
| **Missing teardown**                    | Creates state (an account, an order, a file) without a cleanup path - dangerous specifically against a shared public target like this project's.                 | —                                                                                                                                                                                                                           |
| **Over-mocking**                        | Mocks away the exact thing the test was supposed to verify.                                                                                                      | —                                                                                                                                                                                                                           |
| **Confidently wrong root cause**        | A plausible-sounding explanation for a flaky/failing test gets written down and acted on before it's actually verified - fixing the theory instead of the bug.   | Attributed injected ad text in product names to "server-side concurrency" because it first appeared during a parallel run; a later serial reproduction disproved that - see the log below and `docs/target-application.md`. |
